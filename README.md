# 智能门禁系统

基于 **STM32F103C8T6** 的智能门禁系统，支持 **RFID 刷卡**、**密码开门** 和 **远程控制（ESP-01S + 巴法云）**。采用 **FreeRTOS** 多任务设计，配备 OLED 显示屏和矩阵键盘，交互友好，所有凭证存储在内部 Flash 中，掉电不丢失。

---

## ✨ 功能特点

### 本地功能

- **RFID 刷卡开门**：读取并验证已注册的卡片 UID（支持最多 2 张用户卡 + 1 张管理员卡，可扩展）

- **密码开门**：6 位数字密码（用户级和管理员级），支持键盘输入

- **管理员菜单**：修改密码、增加/删除卡片（通过 4×4 键盘操作）

- **卡片列表查看**：点击“查看卡片”指令后，卡片列表直接在 OLED 上分页显示（无需依赖云端数据存储）

- **实时反馈**：OLED 显示、蜂鸣器、红/绿 LED 指示灯、舵机控制门锁

- **断电保存**：所有凭证存储在内部 Flash 中，掉电不丢失

- **软件看门狗**：基于 TIM2 定时器中断，系统卡死超过 1 秒自动复位

### 远程功能

- **WiFi 配网**：通过网页或 APP 发送 `wifi:新SSID,新密码` 指令，设备将新配置写入 Flash 并自动切换网络

- **远程开门/关门**：通过巴法云发送 `on`/`off` 指令

- **远程管理卡片**：支持 `add_user`、`add_admin`、`del_user`、`del_admin` 指令

- **远程修改密码**：支持 `change_user_pwd` 和 `change_admin_pwd` 指令

## 🧠 软件架构

### FreeRTOS 任务

系统基于 **FreeRTOS**，共创建 4 个任务：

| 任务名           | 优先级         | 堆栈大小 | 功能描述                    |
| ------------- | ----------- | ---- | ----------------------- |
| `defaultTask` | Idle        | 128  | 空闲任务（系统保留 + 喂狗）         |
| `regularTask` | Low         | 256  | 用户界面（OLED、键盘、密码输入、菜单导航） |
| `rc522Task`   | Normal      | 256  | RFID 卡片轮询与验证 + 异常恢复     |
| `userTask`    | AboveNormal | 512  | ESP-01S 通信、心跳包、远程命令解析   |

所有配置数据存储在内部 Flash 中（首次上电自动初始化）：

| 地址           | 内容        | 默认值                 |
| ------------ | --------- | ------------------- |
| `0x08007800` | 用户密码      | `123456`            |
| `0x08007C00` | 用户卡 UID   | `0xBAD3411D`        |
| `0x08008000` | 管理员卡 UID  | `0xC7F57B33`        |
| `0x08008400` | 额外用户卡 1   | `0xFFFFFFFF` (空)    |
| `0x08008800` | 额外用户卡 2   | `0xFFFFFFFF` (空)    |
| `0x08008C00` | 额外管理员卡 1  | `0xFFFFFFFF` (空)    |
| `0x08009000` | 管理员密码     | `111111`            |
| `0x08009400` | 初始化标志     | `0x5A5A5A5A` (已初始化) |
| `0x08009800` | WiFi SSID | `"A"`               |
| `0x08009C00` | WiFi 密码   | `"cr7204612"`       |
| `0x08007FF8` | 用户卡数量     | `1`                 |
| `0x080083F8` | 管理员卡数量    | `1`                 |

> WiFi 配网信息通过 `Flash_WriteString` / `Flash_ReadString` 读写，与修改密码逻辑一致，每次覆盖写入。

## 📋 使用说明

### 上电启动

- OLED 显示欢迎信息，系统进入待机状态，等待刷卡或键盘输入。

### 刷卡开门

1. 将已注册的卡片靠近 RC522 天线。

2. 验证通过：**绿灯亮** + **蜂鸣器响** + 舵机转动开门（约 1 秒后自动关门）。

3. 验证失败：**红灯亮** + 蜂鸣器响（提示错误）。

4. 连续读卡失败 3 次，系统自动重新初始化 RC522。

### 密码开门

1. 按任意数字键开始输入密码（最多 6 位）。

2. 按 **确认键（C）** 验证。
   
   - 默认 **用户密码**：`123456`
   
   - 默认 **管理员密码**：`111111`

3. 正确则开门，错误则红灯报警。

### 管理员菜单

- 进入方式：刷**管理员卡** 或输入**管理员密码**并确认。

- 使用 **↑（U）** / **↓（D）** 选择，**确认（C）** 进入，**退出（E）** 返回。

- 菜单项：
  
  1. **修改密码** – 可修改用户密码或管理员密码（需输入旧密码、新密码、确认新密码）。
  
  2. **添加卡片** – 刷入新卡，然后选择类型（用户卡/管理员卡）。最多可添加 2 张用户卡和 1 张管理员卡。
  
  3. **删除卡片** – 显示所有已存储的卡片列表，选择要删除的卡片（内置的原始卡不可删除）。

### 查看卡片列表（远程触发）

- 网页或 APP 发送 `list_cards` 指令。

- 设备收到后在 OLED 上分页显示所有已注册卡片（用户卡标记 `U`，管理员卡标记 `A`）。

- 按 **↑（U）** / **↓（D）** 翻页，**退出（E）** 返回。

### WiFi 配网（远程触发）

- 网页发送 `wifi:新SSID,新密码` 指令。

- 设备将新配置写入 Flash 并自动重启连接新 WiFi。

- **逻辑与修改密码完全一致**：第一次写入默认值，之后每次覆盖，永远使用最新配置。

## 🌐 远程控制（巴法云）

### 配置信息

- 服务器：`bemfa.com:8344`（TCP 透传）

- UID：`997fb7889ff742939fe5860e41a201d1`

- Topic：`led001`

### 支持指令

| 指令格式                      | 说明                 |
| ------------------------- | ------------------ |
| `on`                      | 开门                 |
| `off`                     | 关门（触发错误报警）         |
| `list_cards`              | 在 OLED 上显示卡片列表     |
| `add_user:XXXXXXXX`       | 添加用户卡（8位十六进制 UID）  |
| `add_admin:XXXXXXXX`      | 添加管理员卡             |
| `del_user:XXXXXXXX`       | 删除用户卡              |
| `del_admin:XXXXXXXX`      | 删除管理员卡             |
| `change_user_pwd:123456`  | 修改用户密码             |
| `change_admin_pwd:111111` | 修改管理员密码            |
| `wifi:新SSID,新密码`          | WiFi 配网（设备自动切换并重启） |

### 通信机制

- 每 15 秒发送心跳包（`cmd=0`）保持连接。

- ESP-01S 使用 **非透传模式**（`AT+CIPSEND=长度`），稳定性优于透传模式。

> 若要适配自己的云平台，请修改 `ESP.c` 中的 `uid`、`topic`、`ssid`、`pswd` 数组。

## ⚙️ 编译与烧录

### 开发环境

- **IDE**：Keil MDK 5 (V5.06)

- **编译器**：ARMCC V5.06

- **HAL 库**：STM32CubeMX 生成的 STM32F1xx HAL

- **FreeRTOS**：V10.0.1

### 注意事项

1. **RAM 空间紧张** – STM32F103C8 仅有 20KB SRAM，若链接报错（L6406E）：
   
   - 检查 `FreeRTOSConfig.h` 中的 `configTOTAL_HEAP_SIZE`（建议 10KB）
   
   - 减小任务堆栈（如 `userTask` 设为 512，`rc522Task` 设为 256）
   
   - 编译优化等级选择 `-O1` 或 `-Os`

2. **供电** – 舵机和 RC522 电流较大，建议使用独立 3.3V 稳压或并联大电容。

3. **巴法云 UID/主题** – 替换为你自己在 [巴法云](https://bemfa.com/) 申请的 UID 和主题。

### 烧录方式

- 通过 SWD 接口（PA13/PA14）或串口 ISP（USART1）下载程序。

# 智能门禁系统

基于?**STM32F103C8T6**?的智能门禁系统，支持?**RFID刷卡**、**密码开门**?和?**远程控制（ESP-01S + 巴法云）**。采用?**FreeRTOS**?多任务设计，配备 OLED 显示屏和矩阵键盘，交互友好。

---

## ? 功能特点

- **RFID 刷卡开门**?– 读取并验证已注册的卡片 UID（支持最多 2 张用户卡 + 1 张管理员卡，可扩展）。

- **密码开门**?– 6 位数字密码（用户级和管理员级）。

- **管理员菜单**?– 修改密码、增加/删除卡片（通过 4×4 键盘操作）。

- **远程控制**?– ESP?01S 连接巴法云（基于 TCP 的轻量 IoT 协议），支持远程开门/报警。

- **实时反馈**?– OLED 显示、蜂鸣器、红/绿 LED 指示灯、舵机控制门锁。

- **断电保存**?– 所有凭证存储在内部 Flash 中，掉电不丢失。

## ? 软件架构

系统基于?**FreeRTOS**，共创建 4 个任务：

| 任务名           | 优先级         | 堆栈大小 | 功能描述                    |
| ------------- | ----------- | ---- | ----------------------- |
| `defaultTask` | Idle        | 128  | 空闲任务（系统保留）              |
| `regularTask` | Low         | 256  | 用户界面（OLED、键盘、密码输入、菜单导航） |
| `rc522Task`   | Normal      | 256  | RFID 卡片轮询与验证            |
| `userTask`    | AboveNormal | 512  | ESP?01S 通信、心跳包、远程命令解析   |

## ? 使用说明

### 上电启动

- OLED 显示?`Smart Access`?和?`Swipe Card...`，系统进入待机状态。

### 刷卡开门

1. 将已注册的卡片靠近 RC522 天线。

2. 验证通过：**绿灯亮**?+?**蜂鸣器响**?+ 舵机转动开门（约 1 秒后自动关门）。

3. 验证失败：**红灯亮**?+ 蜂鸣器响（提示错误）。

### 密码开门

1. 按任意数字键开始输入密码（最多 6 位）。

2. 按?**确认键（C）**?验证。
   
   - 默认?**用户密码**：`123456`
   
   - 默认?**管理员密码**：`111111`

3. 正确则开门，错误则红灯报警。

### 管理员菜单

- 进入方式：刷**管理员卡**?或输入**管理员密码**?并确认。

- 使用?**↑（U）**?/?**↓（D）**?选择，**确认（C）**?进入，**退出（E）**?返回。

- 菜单项：
  
  1. **修改密码**?– 可修改用户密码或管理员密码（需输入旧密码、新密码、确认新密码）。
  
  2. **添加卡片**?– 刷入新卡，然后选择类型（用户卡/管理员卡）。最多可添加 2 张用户卡和 1 张管理员卡。
  
  3. **删除卡片**?– 显示所有已存储的卡片列表，选择要删除的卡片（内置的原始卡不可删除）。

### 远程控制（巴法云）

- ESP?01S 连接巴法云服务器（`bemfa.com:8344`），使用预设的 UID 和主题（`led001`）。

- 发送?`cmd=2&uid=...&topic=...&msg=on`?→ 执行开门。

- 发送?`cmd=2&uid=...&topic=...&msg=off`?→ 触发错误报警（红灯+蜂鸣器）。

- 系统每 15 秒发送一次心跳包（`cmd=0`）以保持连接。

> 若要适配自己的云平台，请修改?`ESP.c`?中的?`uid`、`topic`、`ssid`、`pswd`?数组。

## ?? 编译与烧录

### 开发环境

- **IDE**：Keil MDK 5 (V5.06)

- **编译器**：ARMCC V5.06

- **HAL 库**：STM32CubeMX 生成的 STM32F1xx HAL

- **FreeRTOS**：V10.0.1

### 注意事项

1. **RAM 空间紧张**?– STM32F103C8 仅有 20KB SRAM，若链接报错（L6406E）：
   
   - 减小?`FreeRTOSConfig.h`?中的?`configTOTAL_HEAP_SIZE`（例如设为 6KB）。
   
   - 减小任务堆栈（如?`userTask`?设为 512，`rc522Task`?设为 256）。
   
   - 编译优化等级选择?`-O1`?或?`-Os`。

2. **供电**?– 舵机和 RC522 电流较大，建议使用独立 3.3V 稳压或并联大电容。

3. **WiFi 配置**?– 在?`ESP.c`?中修改?`ssid`?和?`pswd`?为你的 Wi-Fi 名和密码。

4. **巴法云 UID/主题**?– 替换为你自己在?[巴法云](https://bemfa.com/)?申请的 UID 和主题。

### 烧录方式

- 通过 SWD 接口（PA13/PA14）或串口 ISP（USART1）下载程序。

## ? 已知问题与改进方向

- **RC522 读卡偶发性不稳定**?– 可改用硬件 SPI 并增加重试机制，或优化软件 SPI 时序（添加微秒级延时）。

- **退出管理员菜单后偶尔刷卡失效**?– 代码已在退出时执行?`RC522_Reset()`?恢复状态。

- **RAM 严重不足**?– 可考虑优化全局变量、使用?`heap_4`?并进一步减小堆，或更换为 RAM 更大的 MCU（如 STM32F103RE）。

- **远程控制安全性**?– 生产环境中应增加加密和身份认证。
